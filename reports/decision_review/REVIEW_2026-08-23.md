## 3. Root Cause Hypotheses

### H1 — 正分模糊區 default HOLD 承擔過度機會成本損失
- **對應 Pattern**：Pattern A、Pattern E。
- **推論**：跨 agent (Fundamentals, News, Technical) 在保守 stance 下均出現 ~55-60% 高 miss，而 active 決策在相同產業與市況下表現顯著較佳 (miss 12-19%)；問題出在 decision band 與 cap 級聯，而非單一 agent 之信心偏差。
- **驗證需求**：完成 TODO-019/020 權威 join 後重算；等待 Rec 11 fired 樣本累積至 N≥5 且跨 ≥2 regimes。

### H2 — Rec 11 regime guard 設定有效，但樣本量限制了進一步校準
- **對應 Pattern**：Pattern B。
- **推論**：SIDEWAYS 保守 miss 僅 15.0% (準確率 85.0%)，證明 regime guard 將熱區鬆綁限制在 `{RISK_ON, BULL}` 具有高度合理性；擴大至 SIDEWAYS 將引入不必要的虧損風險。
- **驗證需求**：BULL active 樣本累積 N≥5；目前 fired 僅 2 筆 (MU/NVDA) 平均報酬 −5.07%，尚無法支持全面擴大 probe 倉位。

### H3 — news-digest 評估受制於上游輸出格式與資料流通斷層
- **對應 Pattern**：Pattern C。
- **推論**：新版 digest MD header 不再輸出 `session_macro_delta` 散文字串，但底層 JSON 完整保留；資料在 extractor 階段被丟失，導致強訊號母體在回測時被過濾。
- **驗證需求**：實作 TODO-025 authority join，重構 N≥15 強訊號母體後重新評估 hit/miss 分布。

### H4 — Scrape-first 架構造成下游統計系統性偏誤
- **對應 Pattern**：Pattern D。
- **推論**：`build_event_index.py` 長期優先刮取 MD 簡報層而非直接讀取 Phase 5 export 與 digest JSON，造成 `execution_verb` (recall 24.5%)、`hot_zone_eval` (0% 覆蓋)、`macro_delta` (17.8% null) 同步失真。
- **驗證需求**：將資料流改為「權威 JSON 優先、MD 正則 fallback」，使 authority-vs-shadow mismatch 計數歸零。
