## 3. Root Cause Hypotheses

### H1 — HOLD with score 0-1 太頻繁，落點不對齊真實上行（對應 Pattern A + C）
- **推論**：5-lane subagent 投票 + macro_multiplier 合分後，分數落在 0-1 區段被當成「中性偏多但不夠強」→ 預設 HOLD。但 Pattern A 顯示此區段在 Semiconductors / AI infra 多頭環境中本質就是「不夠 conviction 但方向對」，HOLD 等同放棄上行 beta。
- **替代假設**：HOLD 規則本身合理，但 Semiconductors 在 2026-04~05 是非常強多頭（多筆 +40%~+65% 報酬），所有保守 HOLD 都會被市場痛擊；其他 industries 的 HOLD-miss 只有 8/24 = 33%，非系統性偏差。
- **需要更多資料才能定論**：需 regime hook（Pattern H）+ 同期非半導體 HOLD baseline。若下週 H1 與替代假設都成立，建議改 HOLD threshold（提高至 0.5 而非 0）。

### H2 — CANCEL 規則太嚴（對應 Pattern B）
- **推論**：CANCEL 通常觸發於 trader entry 條件未達成 + 風險 flag。9 筆 CANCEL 中 7 筆是市場已開始 break-out，但 entry price 過於保守導致 cancel；事後 stock 繼續走高。
- **替代假設**：CANCEL 本來就是「不進場」的決策，miss=錯過上漲本是 by-design；若這些 cancel 後續 drawdown 也大則合理（保命）。需檢視同期 max_drawdown。
- N=9 還不夠決策。

### H3 — Semiconductors 在當前 cycle 集中下注但系統偏保守（對應 Pattern A + D + E）
- **推論**：Semiconductors 49/123 = 40% 是 deep-dive 量的最大部位；avg miss return +24.9% 表示市場處於 mega-cycle 上行；系統 HOLD/CANCEL 規則對熱門 industry 反而打折，背後可能是 5-lane 投票機制對 Fundamentals / Technical agent 在熱門 industry 過度保守加權。
- **替代假設**：Semiconductors miss 集中只是因為 sample 量大；miss_rate 38.8% 並未顯著高於整體 37%。
- **驗證**：需 decisive_agent hook（Pattern G）以追蹤是哪個 agent 主導 HOLD 決定。

### H4 — news-digest extractor 仍有 V2 format gap（對應 Rec 4 殘留）
- **推論**：`session_macro_delta` 在 backtick + bold + `=` 形式（如 2026-05-18）仍漏抓。
- 驗證明確，已定位 1 筆。

### H5 — momentum-screen verdict 規則或 weights 偏弱（對應 Pattern F）
- **推論**：momentum 多在 neutral / miss，hit 只 3/23。可能是 verdict 期間（30d 標準）對 momentum 短期屬性不適合；或 screen 本身在 2026-04~05 波動環境失靈。
- N=23 preliminary，需累積 8-12 週再評估。
