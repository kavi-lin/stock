- 對應 pattern：B。
- 推論：SIDEWAYS conservative miss 明顯較低，因此把 `{RISK_ON,BULL}` 擴到 SIDEWAYS 會把 probe 放進較不需要鬆綁的區域。

### H3 — news-digest 不是單純 threshold 失效，而是 outcome join 前置資料不完整

- 對應 pattern：C。
- 推論：新 MD 不再穩定複述 `session_macro_delta`；權威 JSON 仍有值。n/a 的強訊號先被資料層遺失，再談 1.0% threshold 會得到偏母體。

### H4 — scrape-first 架構造成偏樣本與 shadow 誤分類

- 對應 pattern：D。
- 推論：同一方向在 `execution_verb`、`hot_zone_eval`、`macro_delta` 三個欄位都出現「權威 JSON 有值、MD scrape 缺或錯」；這是具體 ingestion 證據，不是市場常識推測。

### H5 — PLTR 是 ticker-specific 小樣本，不足以證明 sector 或 agent bias
