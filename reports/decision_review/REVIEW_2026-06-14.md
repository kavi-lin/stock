## 2. 觀察到的 Patterns

### Pattern A：conservative action_class → 高 miss，跨全 agent 一致 [N=71 conservative decided, 信心: 高]
- **觀察**（`decisive_agent_split`）：action_class=**conservative** (HOLD/CANCEL) miss_rate 在**每一個**
  decisive_agent 都偏高 — Fundamentals 58% (11/19)、News 69% (11/16)、Technical 57% (8/14)、
  Sentiment 50% (3/6)、Valuation 67% (2/3)。對照 action_class=**active** (BUY/STAGED_ENTRY/EXECUTE)：
  Fund 18% (7/38)、News 27% (4/15)、Technical 14% (1/7)、Sentiment 0% (2/2)。
- **觀察（action 維度交叉驗證）**：HOLD 43% hit (23H/30M)、CANCEL 22% hit (2H/7M) vs
  BUY 81% (18H/4M)、STAGED_ENTRY 82% (19H/4M)、EXECUTE 75% (6H/2M)。
- root cause 假設 1（**已驗證、已介入**）：正分模糊區 (score∈[0,+staged)) default 落 HOLD，在多頭/top30
  熱區造成系統性錯過 → 已 promote 為 **Rec 11**（v3.41.0, 2026-06-07）。本週 conservative-miss 跨 agent
  均勻 → 再次否證「單一 agent 偏保守」(H3)、支持「decision band 結構性」(H1)。
- root cause 假設 2（待 Rec 11 活化才能否證）：保守性中是否仍有「正確避損」子集——目前 avg_miss_drawdown
  -3.3% (semis) 顯示避損成分極小，但 Internet Content -14.8% dd 提示少數 industry 保守是對的。

### Pattern B：final_score 0–1 模糊區 = 擲硬幣 [N=60 decided, 信心: 高]
- **觀察**：final_score band 0–1 → 48% hit (29H/31M)；對比 1–2 → **74% hit** (32H/11M)、2–3 → 100%
  (2H/0M, n小)、<0 → 57% (4H/3M)。0–1 是唯一接近 50/50 的 band，也是樣本最大 band (n=68)。
- root cause 假設 1：0–1 是 conviction 最弱的區，正好對應 default-HOLD 落點（與 Pattern A 同根）。
  Rec 11 的熱區 probe 正是針對此區的 top30×多頭子集。
- root cause 假設 2：0–1 區可能混入 agent 分歧最大的 case（高 dispersion）→ 需 surface
  agent score 變異數才能分離「弱訊號」vs「強分歧」兩種 0–1。**需額外資料**：tuning_hooks 加
  agent_score_stdev。

### Pattern C：News-decisive deep-dive miss 偏高 [N=31, 信心: 中（<40 門檻）]
- **觀察**：decisive_agent=News 的 deep-dive miss 56% (15/27 eval)，高於 Fundamentals 36%、
  Technical 43%、Sentiment 33%。但拆 active/conservative 後：News-active 僅 27% miss、News-conservative
  69% miss → News 的高 miss **主要來自其主導的保守決策**，與 Pattern A 重疊，未必是 News edge 時效衰減。
- root cause 假設 1：News 主導時更常觸發 HOLD/CANCEL（保守），miss 隨之高 → 與 Pattern A 同根。
- root cause 假設 2：News edge 短時效，window 評估期 News 訊號已失效 → 需 N≥40 + 拆短/長 window 才能分離。
  **TODO-009 累積中** (N=31<40)。
